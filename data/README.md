# Data

## `loan_default.csv` (not committed)

The raw dataset is a LendingClub-style loan-records table (~88 MB, ~123k rows, ~100 columns including `id`, `loan_amnt`, `grade`, `int_rate`, `fico_range_*`, `dti`, `revol_util`, `desc`, `purpose`, `addr_state`, …, and a binary `label` target indicating default).

It is excluded from the repository via `.gitignore` because GitHub warns above 50 MB and rejects files above 100 MB. To reproduce the training notebook, place the file at the repo root:

```
<repo>/loan_default.csv
```

If you derived the file from a public LendingClub dump, document the source and any preprocessing here so collaborators can regenerate it.

## Pickle artifacts (committed)

- `text_analyst_results_train_matched_sample1.pkl` — cached LLM text-analyst outputs for the training sample
- `text_analyst_results_test_matched_sample1.pkl` — cached LLM text-analyst outputs for the test sample

These are kept in-repo so the notebook can rerun fusion / evaluation without paying for LLM calls again. They are regenerated by the relevant cells in [../notebooks/loan_default.ipynb](../notebooks/loan_default.ipynb).
